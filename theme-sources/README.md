# theme-sources/

The owner's original designs (single-file HTML + CSS + small script). They are **inspiration**: each one becomes the
home page of a demo variant, and the other pages follow its visual language.

- Analysis and mapping to categories/variants: `docs/09-design-sources.md`.
- Application code **never imports** from this folder; designs are rebuilt in React + Tailwind (see `.claude/skills/new-template`).
- The designs are the owner's own work. Images they hotlink are downloaded and optimized into the repo before use.
